# Brand assets

Place official logo PNGs here and copy into the theme:

- `logo-banner-yellow.png` — home hero (mustard background)
- `logo-banner-black.png` — dark variant / marketing

Theme runtime copies used by the site:

`theme/big-easy-bodega/assets/images/`

(`logo-banner-yellow.png`, `logo-banner-black.png`, `logo-mark.svg`, `favicon.svg`, plus SVG banner fallbacks)

If both PNG and SVG exist, the yellow **PNG** is preferred for the homepage hero so you can drop in the official artwork without code changes.
